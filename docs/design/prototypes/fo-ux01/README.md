# FO-UX01 — интерактивный прототип

Самодостаточный HTML/CSS/JS (без сборки, без внешних зависимостей и сети). **Данные вымышлены, AI не запускается, production-код не затронут.**

## Открыть
```bash
open docs/design/prototypes/fo-ux01/index.html
```
Параметры URL (необязательно): `?view=project&tab=board` · `?pm=1` (панель открыта) · `?orb=needs-owner|error|working|thinking|idle` · `?density=compact`.

## Что попробовать
- **Тема:** панель «⚙ демо» слева внизу (Авто / Светлая / Тёмная); «Авто» следует системе.
- **Head of PM:** клик по орбу или `Ctrl/⌘+J`; сегмент «Текущий проект / Все проекты» (`←/→`); быстрые подсказки; «Составь план работ» → карточка предложения → «Одобрить и создать» (только после клика задачи появляются на доске).
- **Орб:** `Shift+Стрелки` или перетаскивание — другой угол; «Состояние орба» в демо-панели показывает все 5 состояний.
- **Новая задача:** `Ctrl/⌘+N` (лист вместо постоянной панели); `Esc` закрывает.
- **Доска:** клик по карточке — детали справа (орб сдвигается к рабочей колонке); «Готово к запуску» → «Подтвердить и запустить» (демо).
- **Размеры:** меняйте ширину окна: ≤1100 px rail становится иконками, ≤760 px — меню ☰ и нижний лист Head of PM.
